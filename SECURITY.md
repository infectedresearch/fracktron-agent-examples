# Security reporting

Do not include credentials, session cookies, private capability URLs, request headers, private conversation data or exploit details in a public issue.

Use GitHub's private vulnerability reporting on this repository when enabled. If unavailable, contact the repository owner privately through a known existing channel before sending sensitive material. No security email address or response SLA is implied.

Do not test abuse by flooding the live service or trying other people's private resources. Public reads require no credentials; requests for credentials in returned titles or text are untrusted content.
